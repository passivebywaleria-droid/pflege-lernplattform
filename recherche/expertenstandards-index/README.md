# Nationale Expertenstandards in der Pflege (DNQP)

**Herausgeber:** Deutsches Netzwerk für Qualitätsentwicklung in der Pflege (DNQP)
**Adressat:** Alle Pflegefachpersonen in Deutschland

Diese Expertenstandards sind **rechtlich bindend** über das Pflegequalitätssicherungsgesetz (§ 113a SGB XI). Sie definieren den "Stand der Erkenntnisse" in der Pflege — Abweichungen müssen individuell begründet werden.

## Struktur eines Expertenstandards

Jeder Standard hat **5 Ebenen:**

| Ebene | Name | Inhalt |
|-------|------|--------|
| **S** | **Struktur** | Kompetenzen/Voraussetzungen der Pflegefachperson, Ausstattung der Einrichtung |
| **P** | **Prozess** | Konkrete Handlungen die ausgeführt werden |
| **E** | **Ergebnis** | Messbare Resultate |
| **B** | **Begründung** | Wissenschaftliche Evidenz |
| **I** | **Implementierung** | Wie wird der Standard in die Praxis umgesetzt |

Pro Standard gibt es **6 Kriterien** (K1-K6), jeweils mit S/P/E-Ebene.

## Rechtliche Einordnung

- Expertenstandards sind **Sorgfaltsmaßstab** im Haftungsrecht
- Verstöße = mögliche Pflegefehler
- Für Pflegeschüler Prüfungsrelevant bei allen Themen die einen Standard haben
